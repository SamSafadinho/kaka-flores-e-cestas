# Kaká Lacerda — Flores e Cestas

Site-catálogo da Kaká Lacerda Flores e Cestas, em Brasília. Os visitantes conhecem os produtos e serviços e finalizam o atendimento pelo WhatsApp.

## Site publicado

https://kaka-flores-e-cestas.vercel.app/

## Desenvolvimento

Requisitos: Node.js e pnpm.

```bash
pnpm install
pnpm dev
```

Para gerar a versão de produção:

```bash
pnpm build
```

## Estrutura principal

- `src/CommunityApp.jsx`: conteúdo e componentes da página.
- `src/community.css`: identidade visual e responsividade.
- `src/analytics.js`: Google Analytics, Meta Pixel e eventos do catálogo.
- `public/images`: imagens utilizadas no site.

## Atualizações

Produtos, textos, imagens e seções podem ser alterados diretamente no código. Antes de publicar, revise o site em telas de computador e celular e confirme se os links do WhatsApp e Instagram continuam corretos.
